# Customer-Behaviour-Dashboard

# Overview

This project demonstrates an end-to-end data analytics workflow, from exploring and cleaning raw data to extracting insights using SQL and visualizing results through an interactive Power BI dashboard.

The project uses Python for Exploratory Data Analysis (EDA) and data cleaning, PostgreSQL for querying and analyzing data, and Power BI for presenting key findings through visualizations.

# Dataset

The dataset contains the raw data used for analysis. It was explored and cleaned to improve data quality and prepare it for further analysis.

# Key activities:

Examined the dataset structure and data types.

Identified missing values, duplicate records, and inconsistencies.

Cleaned and prepared the data for analysis.

Used the cleaned data for SQL queries and dashboard development.

# Tools & Technologies

Python: Exploratory Data Analysis (EDA)

Pandas: Data manipulation and cleaning

Jupyter Notebook: Interactive analysis and documentation

PostgreSQL: Data querying and analysis

SQL: Filtering, aggregation, grouping, joins, and analytical queries

Power BI: Interactive dashboard development

GitHub: Project documentation and version control

# Project Steps

1. Exploratory Data Analysis (EDA)

Loaded the dataset into Python using Pandas.

Examined rows, columns, data types, and summary statistics.

Identified patterns, trends, and potential data quality issues.

2. Data Cleaning

Handled missing values and duplicate records where necessary.

Addressed data type inconsistencies.

Prepared a clean dataset for further analysis.

3. SQL Analysis Using PostgreSQL

Imported the cleaned dataset into PostgreSQL.

Wrote SQL queries to explore the data and answer analytical questions.

Used filtering, aggregation, grouping, joins, and other SQL techniques to identify meaningful patterns and trends.

4. Power BI Dashboard

Connected the analyzed data to Power BI.

Created visualizations and key performance indicators (KPIs).

Designed an interactive dashboard to communicate findings clearly.

# Dashboard

The Power BI dashboard presents the key findings through interactive visualizations, charts, and KPIs, enabling users to explore the data and understand important trends.
